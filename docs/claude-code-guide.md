## 한 줄 요약

**클로드 코드는 "대답만 하는 AI"가 아니라, 내 폴더의 파일을 직접 읽고·고치고·명령까지 실행하는 AI 작업 동료예요.**
그리고 잘 쓰는 비결은 딱 하나 — **"맥락(컨텍스트)을 많이 줄수록 결과가 좋아진다."**

## 02. 영상에서 말하는 클로드의 장점 10가지

### ① 터미널에서 직접 일하는 AI
채팅창에 복붙할 필요 없이, 파일을 **직접 읽고, 고치고, 명령을 실행**해요.

### ② 내 파일·코드에 대한 질문에 강하다 (4:19)
"이 파일은 어디에 쓰여?", "왜 이렇게 만들었어?" 같은 질문으로 시작하는 게 보리스가 가장 먼저 추천하는 사용법이에요. 새로운 저장소를 파악하는 시간이 확 줄어요.

### ③ 바뀐 기록(Git 히스토리)까지 찾아준다 (6:04)
"이 파일 언제, 왜 바뀌었어?" 라고 물으면 Git 기록을 뒤져서 알려줘요.

### ④ 고치기 전에 계획부터 세운다 (7:53)
바로 고치게 하지 말고 **"해결 방법 몇 개 제안해 줘"** 라고 먼저 생각하게 하면 원하는 결과에 더 빨리 도달해요.
👉 `Shift + Tab` 으로 **계획 모드**로 바꿀 수 있어요.

### ⑤ 우리 팀 도구를 연결해서 쓴다 (9:55)
쓰는 도구 이름과 사용법을 알려주거나 **MCP 서버**로 연결하면, 클로드가 그 도구를 직접 써요.

### ⑥ 검증된 작업 순서가 있다 (11:02)
1. **살펴보기 → 계획 → 만들기**
2. **테스트 먼저 쓰고** 그 테스트를 통과하게 만들기
3. **목표 화면(이미지)과 비교하며** 반복해서 고치기

### ⑦ CLAUDE.md로 규칙을 기억한다 (12:17) ⭐ 가장 중요
"맥락을 더 줄수록 결과가 좋아진다"가 이 영상의 핵심이에요.
- `/init` : 현재 폴더에 맞는 CLAUDE.md 첫 버전 자동 생성
- `/memory` : CLAUDE.md 열어서 고치기
- 대화 중 **"이건 앞으로 기억해 줘"** 라고 말해도 돼요

### ⑧ 설정을 팀과 나눌 수 있다 (15:50)
| 파일 위치 | 누가 쓰나 |
|---|---|
| `프로젝트/CLAUDE.md`, `.claude/settings.json`, `.mcp.json` | 팀 전체 공유 (Git에 올림) |
| `프로젝트/CLAUDE.local.md`, `.claude/settings.local.json` | 나만 사용 |
| `~/.claude/CLAUDE.md` | 내 모든 프로젝트에 공통 |

### ⑨ 자동화에 끼워 쓸 수 있다 (20:52)
`claude -p "질문"` 으로 답을 받아 스크립트나 CI에 연결할 수 있어요. (개발자용)

### ⑩ 여러 개를 동시에 돌릴 수 있다 (22:37)
클로드 코드를 여러 창에 띄워 각자 다른 일을 시키는 방법. 가장 고급 사용법이에요.

## 03. 단축키·명령어 한 장 📌

### 단축키
| 키 | 기능 |
|---|---|
| `Shift + Tab` | 작업 방식 바꾸기 (하나씩 묻기 · 자동 수락 · 계획만 세우기) |
| `Esc` | 하던 일 멈추기 |
| `Esc Esc` | 이전 시점으로 되돌리기 |
| `@` | 파일 이름을 골라 클로드에게 알려주기 |
| `!` | 바로 셸 명령 실행하고 결과를 클로드에게 보여주기 |

### 명령어
| 명령어 | 기능 |
|---|---|
| `/init` | CLAUDE.md 첫 버전 만들기 |
| `/memory` | CLAUDE.md 고치기 |
| `/clear` | 새 대화 시작 |
| `/compact` | 대화 요약해서 공간 비우기 |
| `/resume` | 이전 대화 이어서 하기 |
| `/permissions` | 미리 허용할 작업 정하기 |
| `/terminal-setup` | `Shift + Enter` 줄바꿈 켜기 |
| `/theme` | 화면 색 바꾸기 |

| 영상의 팁 | 이 저장소에 적용한 것 |

| ⑦ CLAUDE.md로 규칙 기억 | 루트에 `CLAUDE.md` 생성 → 폴더 구조, 파일명 규칙(`YL134-C4.jpg`), 이미지 규격(1000×1000 JPG / 780px PNG), 커밋 메시지 형식, 블로그 말투까지 기록 |
| ④ 고치기 전에 계획부터 | CLAUDE.md에 "여러 장 바꾸는 작업은 먼저 계획을 보여줄 것" 규칙 추가 |
| 안전하게 쓰기 | "파일 삭제·덮어쓰기 전에는 반드시 확인" 규칙 추가 (쿠팡에 걸린 이미지 URL이 깨지지 않도록) |
| ⑧ 팀과 설정 공유 | CLAUDE.md를 Git에 올려 어디서 클로드를 켜도 같은 규칙 적용 |
